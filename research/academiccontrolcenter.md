## 🌌 Overview

The **Academic Control Center** is a sleek, single-page application built to transform boring study routines into an engaging, gamified experience. Manage your tasks as "Missions", track overdue assignments, earn ranks, and visualize your academic journey—all within a beautifully designed, dark-mode native interface. 

---

## ⚡ Features

- 🌑 **Dark Mode First:** A visually appealing, high-contrast dark theme that is easy on the eyes (includes light mode).
- 🎯 **Mission Tracking:** Create, edit, and organize academic tasks as distinct missions.
- 🏆 **Gamified Progression:** Earn ranks, level up, and track your academic standing.
- 📊 **Export Capabilities:** Instantly generate PDF reports of your progress utilizing `html2canvas` and `jsPDF`.
- 📱 **Fully Responsive:** Styled with TailwindCSS to look perfect on any screen size.
- ⚡ **Zero Setup:** Pure HTML, CSS, and JS. Just open the file and start controlling your academics.

---

## 🛠️ Tech Stack

- **Structure:** HTML5
- **Styling:** TailwindCSS (via CDN), Custom CSS Variables, Google Fonts (Poppins)
- **Logic:** Vanilla JavaScript, UUID generation
- **Utilities:** `html2canvas`, `jspdf`

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/academiccontrolcenter.git
   ```
2. **Open the file:**
   Simply double-click `Academic Control Center.html` to open it in your favorite modern browser. No build steps or local development servers required!

## 🎨 Interface Highlights

The application features a modern card-based layout designed for productivity:
- **Mission Cards:** Color-coded highlights for critical and overdue tasks.
- **Rank Badges:** Visual indicators of your current academic tier and achievements.
- **Dynamic Filtering:** Sort, search, and manage your missions intuitively.
