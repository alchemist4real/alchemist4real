## ✦ 01. THE VOID
**174 Archive** (also known as the *beenbrain PRO System*) is a highly interactive, aesthetic web operating system and digital archive. Designed with meticulous attention to typography, spacing, and interaction, it transforms standard web browsing into an immersive desktop experience. 

## ✦ 02. CORE MODULES
- 🪟 **Window Manager** — A sleek, draggable macOS-inspired window system with floating docks and void animations.
- 📂 **Digital Explorer** — Seamless grid and dashboard views to traverse archived files and sub-systems.
- 🎵 **Spotify Integration** — Live track synchronization and embedded "now playing" artifacts.
- 🌑 **Dark Aesthetics** — Custom themes leveraging `Playfair Display` and `JetBrains Mono` over a deep ink palette.
- 📱 **Capacitor Integration** — Ready to be bundled and deployed natively via Android and Web.

## ✦ 03. ARCHITECTURE
The system is powered by vanilla web technologies supercharged by **TailwindCSS** and **CodeMirror** for internal text rendering. The build pipeline (`build-app.js`) automatically compiles and structures the `dist` environment, isolating the core OS and archive modules (`os.html`, `admin.html`, `index.html`) from the raw source.

## ✦ 04. DEPLOYMENT
```bash
# Install dependencies
npm install

# Build the system distribution
npm run build
```
