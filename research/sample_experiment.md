# Analyzing User Interaction in Dark Mode UI
We conducted an experiment to measure the retention rate and engagement levels of users when exposed to a brutalist, dark-mode interface versus a standard clean white UI. The results showed a 40% increase in average session duration for the dark-mode variant.
Participants reported feeling more focused and less visually fatigued, indicating that for complex data-heavy applications, dark mode is not merely an aesthetic choice, but a functional imperative.
