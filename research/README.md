# Research & Documents

Upload your Word, PDF, or any other research documents directly into this folder.

To link to a file from `data.json`, use the path like this:
```json
{
  "id": "R01",
  "title": "My New Research Paper",
  "description": "A comprehensive study.",
  "tags": ["PDF", "Health"],
  "link": "/research/my-paper.pdf"
}
```
Vercel will automatically serve the file and people can download or view it!
